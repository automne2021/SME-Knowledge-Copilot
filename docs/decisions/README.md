# Architecture Decision Records

Mỗi quyết định trong spec mục 14 có một file riêng khi bắt đầu code phần liên quan, ví dụ `0001-python-tool-loop.md`.

Mẫu:

```markdown
# ADR-XX: <tiêu đề>

- Trạng thái: Đã chốt | Thay thế bởi ADR-YY
- Ngày: YYYY-MM-DD

## Bối cảnh
## Quyết định
## Lý do và đánh đổi
## Điều kiện xem lại
```
