# 03-T1 — Schema, migration và API thư mục

**Ngày:** 18/11/2026 (Asia/Saigon). **Nhánh:** `feat/03-folders`, tạo từ `main` tại `7aa1509`. **Phạm vi:** chỉ 03-T1, theo xác nhận “Thực hiện đi” của người dùng. Chưa push/merge.

## Hành vi đã triển khai

- Tạo bảng `folders` với UUID, workspace, creator, tên và timestamps. Tên API được trim, dài 1–100 ký tự; PostgreSQL unique index `(workspace_id, lower(name))` chặn tên trùng cả khi bỏ qua API. Giữ dấu tiếng Việt; không thêm dependency `citext` hay thay collation.
- Thêm `documents.folder_id` nullable. Hai FK bổ sung nhau: FK đơn `ON DELETE SET NULL` chỉ đổi folder ID; FK kép bảo vệ workspace. Creator của folder cũng có FK kép với user/workspace. Dữ liệu cũ giữ nguyên và bắt đầu chưa phân loại.
- `GET /api/v1/folders` cho thành viên đọc, gồm thư mục rỗng và `ready_document_count`, sắp theo `(lower(name),id)`. `POST`, `PATCH`, `DELETE` dành cho `knowledge_admin`; member ghi 403, thiếu danh tính 401, ID ngoài workspace/không tồn tại 404. Tên trùng trả 409 `duplicate_folder`.
- Xóa API khóa folder `FOR UPDATE` rồi kiểm tra mọi document row còn tham chiếu, không dùng số đếm ready để suy ra thư mục rỗng. Còn tài liệu → 409 `folder_not_empty`; thư mục rỗng → 200 `{id,deleted:true}`. Không cascade xóa tài liệu.
- Migration `20261118_folders` nối `20261103_rag04`; downgrade từ chối nếu còn folder row để tránh mất phân loại âm thầm. Chỉ migrate DB test trong đợt này.

**Probe khóa bổ sung (đã chạy, không thuộc số đếm pytest):** inline Python `-B -`, dùng URL test qua `validate_test_database_url`, hai `Session` độc lập và `SET LOCAL lock_timeout='300ms'`. Tạo UUID workspace/user/folder/document riêng; (1) session A khóa folder qua `locked_folder`, session B insert document bị PostgreSQL `55P03`; (2) B insert chưa commit giữ FK key-share, A gọi `delete_folder` bị `55P03`; (3) B commit, A xóa nhận 409 `folder_not_empty`. Cả ba assert đạt. `finally` đóng session, xóa đúng các row UUID của probe, commit và xác nhận workspace probe không còn. Đây là probe một lần, chưa là bài kiểm thử tải/concurrency diện rộng.

## Đánh đổi và giới hạn

- **Tên:** chọn expression unique index thay vì check-then-insert ở service vì check đơn lẻ có race; `citext` cần extension và thêm vận hành nên chưa chọn. `lower(name)` không tự gộp Unicode canonical equivalents; chưa thêm quy tắc Unicode normalization khi contract chưa yêu cầu.
- **FK:** hai FK tránh `SET NULL` trên cả hai cột composite, vốn có thể vi phạm `workspace_id NOT NULL`; phương án PostgreSQL-specific `SET NULL (folder_id)` gọn hơn ở SQL nhưng cần tùy biến biểu diễn/so sánh trong SQLAlchemy/Alembic. Giữ model/migration thông thường và đã kiểm chứng không drift; xem lại nếu nâng stack hỗ trợ trực tiếp.
- **Thư mục rỗng:** áp dụng nghĩa bảo thủ “không còn document row tham chiếu”, gồm cả `deleted` tombstone. Vì thế thư mục chỉ có tombstone cũng không xóa qua API; nếu sản phẩm muốn chỉ tính tài liệu còn sống, cần chốt lại contract và test. FK SET NULL không tự cấp quyền bỏ qua kiểm tra ở API.
- **Vận hành:** web do launcher quản lý đã được dừng để chạy tests và chưa khởi động lại. Chưa migrate DB development; cần áp dụng migration trước khi chạy phiên bản backend này với DB development.
- **Ngoài T1:** chưa có API gán/upload/lọc documents theo folder, chưa có search/chat folder scope, chưa đổi UI. Không chạy frontend/eval suite vì không sửa frontend, `eval/` hoặc service eval sử dụng. Không có số đo retrieval mới, không tự duyệt human review.
- **Ngân sách:** 0 lời gọi Gemini, 0 USD; không đổi model/prompt/config, không bật billing hoặc fallback trả phí.
